## 🧭 Sobre este repositorio


Este portafolio reúne los proyectos desarrollados durante mi formación como Data Analyst en **Desafío Latam**, aplicando SQL, Power BI, Python y narrativa de datos sobre casos de negocio reales.

### ¿Por qué GitHub como repositorio?

- **Control de versiones y trazabilidad**: cada proyecto muestra su historial de trabajo, no solo el resultado final.
- **Alojamiento gratuito con GitHub Pages**: permite publicar el portafolio sin costo, con dominio propio.
- **Estándar de la industria**: es la plataforma que reclutadores y equipos técnicos revisan por defecto al evaluar candidatos en análisis de datos.
- **Integración con las herramientas del oficio**: notebooks, scripts SQL, dashboards y documentación conviven en el mismo lugar donde también se practica control de versiones.

## ✅ Buenas prácticas aplicadas en este portafolio

- **Consistencia y personalización**: todos los enlaces y descripciones corresponden a trabajo real, sin textos de plantilla sin completar.
- **Documentación clara por proyecto**: cada proyecto explica el objetivo, las herramientas utilizadas, el proceso y los resultados obtenidos.
- **Calidad sobre cantidad**: se prioriza mostrar proyectos sólidos y bien documentados por sobre una gran cantidad de ejercicios sueltos.
- **Actualización periódica**: este repositorio se revisa y actualiza a medida que se completan nuevos proyectos del bootcamp.
- **Accesibilidad de los enlaces**: todos los enlaces de este README son de acceso público, verificados antes de su publicación.
